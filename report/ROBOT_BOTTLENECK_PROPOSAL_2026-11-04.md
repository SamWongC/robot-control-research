# 真实机器人瓶颈与候选命题：接触推动中的决策保持仿真细化

日期：2026-11-04。决定：**有依据进入小规模可证伪试验；尚未确认创新，尚未授权或执行大规模新项目。** 本次完成定向文献检索与命题设计，没有复现实测时间、安装新环境或运行机器人实验。

## 1. 推荐一个具体问题

工作题目：**面向机器人接触推动的决策保持多精度轨迹评估**。

英文：**Decision-Preserving Multi-Fidelity Rollout Evaluation for Contact-Rich Robotic Pushing**。

主攻对象：机械臂用推杆移动、旋转非凸平面物体，完成有障碍物的目标姿态任务。先从Push-T类任务的仿真与固定候选动作批次开始，再扩展绕障推动。不要同时承诺四足全身控制、未知时延、视觉感知、摩擦辨识和神经网络安全。

要解决的不是“再提出一个采样MPC”，而是：**在一次规划中，只精细模拟真正影响候选优劣判断的接触片段，同时保留相对于指定精细仿真模型的决策质量证据。**

## 2. 来源不是假想问题

- **牛津/RAI/Cornell，GPC作者稿v2**：Spot推动椅子绕C形障碍物；作者报告轨迹展开占总计算超过90%，主要来自碰撞与接触动力学，整体约5Hz。定位§V-B Computation Time。该数字是作者实现上的测量，不是我们电脑的结果。[论文](https://arxiv.org/html/2510.14643v2)
- **TU Darmstadt等，2026作者预印本**：Franka Research 3执行真实Push-T；§III-B报告RTX5090上8–10Hz重规划，§V指出小积分步长与长规划时域的矛盾。它支持“GPU并行后仍存在取舍”，不是所有GPU实现都达不到更高频率的证明。[论文](https://arxiv.org/html/2606.20712v1)
- **宾大GRASP，2025 RA-L项目**：Franka对非凸物体非抓取操作，采用全局接触前位置采样加局部接触隐式优化；§VII仍讨论效率限制。说明“把采样和局部接触模型结合”不能作为新主张。[论文](https://arxiv.org/html/2505.13350v1)、[作者项目页](https://approximating-global-ci-mpc.github.io/)

Oxford学位论文及ORA部分文件访问403；本次关键事实由可访问的GPC作者稿核查，不声称全文读过受阻的学位论文。没有找到并核验GPC训练权重与完整官方代码，不能承诺一键精确复现。

## 3. 已有方法究竟解决了什么

| 方法 | 证据和正确判断 | 对候选方向的限制 |
|---|---|---|
| 学习采样先验 | GPC改善候选生成，但其作者仍报告展开瓶颈 | 新工作应在相同候选批次上测评估开销，不能用更好的采样混淆结果 |
| GPU并行 | Darmstadt的真实任务仍有积分精度/时域取舍 | 必须与批处理GPU基线比较，不能只打败串行Python |
| 缓存与证书 | [CacheMPC预印本](https://arxiv.org/html/2606.28300v1)在已排定接触的凸QP上认证缓存；表VI硬件完整证书版本p50为3342μs，基线1883μs，拒绝后重复求解抵消收益 | 这是该设置的负面时间结果，不是证明所有缓存无效；“缓存+验证”已不是新思想 |
| 管束/抽象 | [管束增强多阶段MPC](https://eldorado.tu-dortmund.de/bitstreams/92837a99-43d4-4dd9-aaeb-f0058d9e1d53/download)针对分支复杂度与鲁棒控制有保证 | 不能自动省掉碰撞求解，也不能因此宣称它们不能用于推动；需要同任务误差/保守性/时间比较 |
| 自适应模型精度 | [Adaptive Dynamics Orchestration预印本](https://arxiv.org/html/2606.00085v1)已经依据误差、代价和场景选择模型，见§IV | “简单场景低精度、复杂场景高精度”不够新；我们拟评估同一批候选的排名误差 |
| 多精度最优候选识别 | [NeurIPS2022](https://proceedings.neurips.cc/paper_files/paper/2022/file/71c31ebf577ffdad5f4a74156daad518-Paper-Conference.pdf)及[NeurIPS2024](https://papers.neurips.cc/paper_files/paper/2024/file/dc9e095f668044e7a0909a4ea3926beb-Paper-Conference.pdf)已有低成本有偏评估与淘汰理论 | 上下界淘汰本身不是创新；关键是机器人接触中廉价有效的偏差界从何而来 |

**已确认的是实际瓶颈及上述方法的适用范围；未确认的是它们在我们尚未运行的推动基准上都表现不足。** “所有现有方法仍解决不好”需要公平实验，不能由不同论文的频率数字拼接得出。这里是可测试的候选缺口，不是已认证空白。

## 4. 精确命题及原创性所在

固定当前状态和有限候选批次 U_1,...,U_K。定义J_H(U_i)为指定精细离散接触模型的成本，模型、步长、接触求解精度、时域与成本均冻结。高精度参考不是物理真值。

**核心待证命题P1（尚未成立）**：在明确的接触模型、参数域和良定性假设下，使用粗轨迹、局部接触求解残差、间隙/接触模式裕度及选择性细化，构造候选成本包络

    L_i <= J_H(U_i) <= U_i^bound,

且包络的在线计算不要求先完整执行该候选的精细轨迹。对于模式即将切换、擦边、模式未确定或病态残差的片段，必须细化或拒绝出具证书，不能外推稳定模式的界。

可能的新贡献是**跨接触建立/脱离时仍有效、又比完整精细评估便宜的成本误差包络及细化策略**。若仅使用全局Lipschitz常数放大误差、同模式KKT灵敏度或现成置信区间，再套淘汰规则，则未证明超出已有框架直接应用。

第一次数学范围宜限于平面、有限候选接触和明确的正则化接触求解器。必须写出唯一性/条件数/几何界等条件如何检查。MuJoCo粗细步长的数值差异本身不是可靠误差上界；不能假设任意摩擦刚体模型存在统一界。若假设排除了测试中大部分接触切换，证书即使正确也缺少实用意义。

**附属引理P2（标准，不作创新）**：选择候选j，如果

    U_j^bound - min_i L_i <= epsilon,

则J_H(U_j)-min_i J_H(U_i)<=epsilon。这只需上下界有效。成本上界不能冒充碰撞安全证书；参考成本含惩罚也不等于硬约束保证。

**预算声明P3**：限时停止时报告当前可验证差距，而不是保证任何预算下都能达到epsilon。证书不充分时返回“未认证”。决策频率和任务成功率由闭环实验评价，不能由单次排名引理推出。

先使用选择最低成本样本的predictive sampling。CEM保留整组精英、MPPI使用加权更新，不与单个最优样本选择等价；后续扩展必须分别证明精英集合或权重误差，不能直接套P2。

## 5. AI应该放在哪里

可用小模型预测“哪个候选、哪个时间片值得进一步细化”，学习计算资源分配。模型只负责优先级；实际成本包络由数学验证器给出。这样学习模块失败影响效率而非伪造证书。

学习优先级也必须和无学习贪心误差细化、固定细化比例、多精度候选淘汰相比。若无学习策略同样好，就不增加神经网络。无需先训练大模型或端到端视觉控制器。

## 6. 第一轮复现与淘汰试验

这一步应先于正式立题，尚未执行。

1. 建立Push-T接触/脱离/换边推动场景，冻结状态快照和候选控制批次；初期可用64/128候选，数值是资源规划不是已测可行配置。
2. 用精细模型离线完整评估同一批次，保存每段接触事件、成本、时间。固定初态、模型和候选，不把不同采样策略混入评估比较。
3. 比较全精细、全粗糙、GPU批处理、warm start、带当前初态误差核验的缓存、固定比例细化、通用多精度淘汰、适用的局部代理/管束包络。记录不适用的假设，不能把未实现的基线标成失败。
4. 将开发与独立测试按场景和轨迹分开。测试中增加接触边缘、姿态误差和几何变化；参数变化若超出包络声明范围，应标成不支持而非继续使用证书。
5. 报告总耗时p50/p95/p99、同步后的GPU时间、证书覆盖率、错误包络数、细化比例、候选排名差距，以及闭环成功率。少算仿真次数未必更快，分支发散与小批量可能损害GPU吞吐。

建议预先登记的工程去留线：相同候选集和参考误差标准下，包含验证开销的总p95时间至少下降30%，且独立测试中没有发现错误证书；闭环性能须另作非劣比较。30%是项目门槛而不是期刊标准，测试未发现错误也不替代数学证明。若每次都需全精细回退、误差界过宽或全GPU基线更快，停止这条算法路线。

## 7. 资源与复现现实

[Hydrax](https://github.com/vincekurtz/hydrax)是可用候选基础设施，提供JAX/MJX采样MPC；本次仅检查公开文档，未安装、未核验我们平台兼容性，也不是GPC论文的已核验完整复现。8GB笔记本GPU足以作为缩小问题的试验起点这一判断仍需实测显存和时间，不能承诺重现RTX5090结果。先CPU小批次核验方法，再做GPU时间比较。实机验证可后续依托RWTH机械臂平台，尚无已确认设备访问。

## 8. 与原项目的关系及结论

旧延迟项目保留为研究训练与审计资产，不强行把延迟并入新问题。此处来自真实接触任务，而不是为了复用旧代码而制造的任务。

建议选择本候选作为下一轮小规模研究试验。当前证据等级：任务存在=已确认；计算瓶颈=作者报告且已定位；现有方法总体不足=未做本地实证；新成本包络定理=未证明；RA-L可投稿性=未确认。这样既给出明确研究入口，也避免再次把研究愿望当成创新结论。
